# ReTrack 🚀

ReTrack is a smart assistant mobile application that helps users manage important information by combining manual reminders with automatically detected insights such as parcel tracking, billing notices, and work-related updates.

---

## ✨ Features

* 📝 **Manual Reminders**

  * Users can add and manage their own reminders easily.

* ⚡ **Smart Detection**

  * Automatically identifies important information such as:

    * 📦 Parcels (tracking numbers & delivery status)
    * 💳 Billing notices (payment reminders)
    * 💼 Work-related emails (meetings, tasks)
    * 🔔 Alerts (notifications & OTPs)

* 🔍 **Email Scanning Simulation**

  * Simulates scanning incoming emails and extracting actionable insights.

* ⚙️ **Customizable Settings**

  * Users can configure:

    * Work email domain
    * General email preferences
    * Account information

---

## 🧠 How It Works

ReTrack processes incoming data (simulated emails) and applies parsing logic to extract key information.
These insights are then categorized and displayed in a clean, user-friendly interface.

---

## 🛠️ Tech Stack

* **Frontend:** React Native (Expo) with TypeScript
* **UI Components:** React Native + Ionicons
* **Backend (Optional):** Firebase (Firestore for storage)

---

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ccyenoc/ReTrack.git
cd ReTrack
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the app

```bash
npx expo start
```
